# TVD for STMBJ
Total Variation Denoising for STMBJ (and other data forms) script using skimage.restoration/ denoise_tv_chambolle

## Description
This project provides software for to denoise, in general, any 1D time-series datasets (incl. STMBJ/MCBJ/EMJs etc). It asks for a user input column (0-indexed) and denoises that column based on a specified regularisation weight (larger = smoother), then creates a new folder and saves files to that new folder with the specified column replaced by the denoised signal. It is part of ongoing research in the field of molecular electronics at the University of Liverpool.
